# 🧠 Sentiment Analysis with Large Language Models

This project demonstrates how to perform sentiment analysis on textual data using powerful Large Language Models (LLMs). Built within a Jupyter Notebook, it shows how to classify text as **positive**, **negative**, or **neutral**, helping extract meaningful sentiment insights from raw data.

## 📌 Features

- ✅ Sentiment classification using LLMs
- 📊 Jupyter Notebook for interactive experimentation
- 💬 Text preprocessing and cleaning
- 📈 Visualizations for sentiment distribution
- 📁 Easy to customize with your own dataset
